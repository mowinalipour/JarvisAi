# Jarvis AI v0.1

Minimal Persian voice assistant Android prototype.

## Build
GitHub Actions automatically runs on pushes to main. Open Actions > Build Jarvis APK > latest successful run > Artifacts > JarvisAI-debug-APK.

## Current features
- Persian voice recognition through the device's available speech recognition service
- Persian TTS when supported by the installed speech engine
- Open Android Settings via spoken command
- Simple offline command matching

This is an initial prototype, **not** a fully autonomous hybrid AI assistant. No online AI backend is connected yet. It has not been device-tested.
